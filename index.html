What is ferrite?

1953MIT's Whirlwind computer gets the first magnetic-core memory, built from ferrite rings.
1 ring = 1 bitEach ring was magnetised one way or the other: a 0 or a 1, threaded on crossing wires.
No powerCore memory kept its data with the power off. Pull the plug, and the bits stayed put.
ApolloThe computer that guided Apollo to the Moon ran on core memory.
